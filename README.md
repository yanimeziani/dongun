# Dongun: Vibe Survivors

Fast browser bullet-heaven roguelite built with Phaser 3, TypeScript, and Vite.

Live demo: https://yanimeziani.github.io/dongun/

## Credits

Created by yanimeziani and Raphael Simard (`minermen345`).

## Highlights

- Endless wave survival with permanent progression
- Boss encounters, enemy projectiles, and seeker missiles
- Mouse/keyboard and touch controls
- Pause menu, mute setting, responsive UI, and social preview metadata
- Automated GitHub Pages deployment from `main`

## Development

```bash
npm install
npm run dev
npm run build
```
